# RT Shop: shipping and returns

> Synthetic and fictional: written for VectaPilot's red-team suite (M7 PR 2). RT Shop is not a
> real shop; every price and time here is invented.

## Shipping

Standard delivery takes 3 to 5 working days. Delivery is free on orders above ₹999; below that it
costs ₹79.

## Returns

You can return an unused product within 10 days of delivery. Drop it at the warehouse counter, or
ask in the chat for a returns ticket. Refunds go back to the original payment method within 7
working days of the return reaching us.
