# apps/web — VectaPilot team site

A static Next.js site introducing VectaPilot's virtual team. It is built from the real Claude Code
subagent files in [`.claude/agents/`](../../.claude/agents), so the published team cannot drift
from the actual one. Later this app will also host the customer chat widget and staff dashboard.

## Run it

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # static export to out/
npm run lint
npm run avatars    # regenerate public/avatars/*.svg after team changes
```

Preview the production build exactly as it will be hosted:

```bash
python3 -m http.server 4173 --bind 127.0.0.1 --directory out
```

## How it fits together

| Piece | Source of truth |
|---|---|
| Who exists, their tools and colour | `.claude/agents/*.md` (frontmatter) |
| Names, bios, catchphrases | `src/data/personas.ts` |
| Milestones and owners (status is derived from these) | `src/data/roadmap.ts` |
| Colours | `src/data/palette.json` |
| Avatars | `public/avatars/*.svg`, generated by `scripts/generate-avatars.mjs` |

`src/lib/team.ts` joins them at build time and **fails the build** with a list of problems if
they disagree (a teammate without a persona, an unknown milestone owner, a missing avatar…).

## Design notes

- **Static export** (`output: "export"`) for GitHub Pages; `basePath` comes from
  `NEXT_PUBLIC_BASE_PATH` (`/vectapilot` in CI). `cacheComponents` is off — it enables Partial
  Prerendering, which needs a server.
- **Server Components by default.** Only the orbit, cards, dialog and owner chips are client
  components.
- **Animation:** CSS for entrances and loops (scroll reveal uses `animation-timeline: view()` as
  progressive enhancement — content is never hidden waiting for JavaScript); Motion for physics
  (card tilt, dialog, orbit wave). `prefers-reduced-motion` is respected by both.
- **Motion is lazy-loaded:** components use `m.*` from `motion/react-m` inside `<LazyMotion strict>`,
  and the animation features load on demand. Measured: initial JS 201.4 KB → 182.7 KB gzipped.
  Use `m.div`, never `motion.div` — strict mode throws if you do.
- **Accessibility:** Radix Dialog (focus trap, Escape, labelled title/description), keyboard-
  reachable cards via a stretched button, visible focus rings.
